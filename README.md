### Hi, I write visual study notes and hands-on tutorials.

I turn course material into clean, typeset PDF handouts with diagrams, and I write step-by-step guides for things I actually got running on my own machine: ROS 2, Ubuntu, and computer vision papers.

**Everything here is free to read. If something saves you time, a star helps more people find it.**

New handouts and tutorials are announced on X: [@GustavNerniyiz](https://x.com/GustavNerniyiz)
